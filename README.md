# Fresh Chicken

A mobile-first ordering website prototype for Fresh Chicken.

## Included
- Product catalogue with the supplied prices
- Cart and quantities
- Custom Fresh Box builder with GH₵10 discount
- Classic and Deluxe fixed combos
- Checkout with UCC delivery locations
- GH₵5 delivery fee
- Same-day and scheduled delivery
- Scheduled delivery forces payment-after-placing-order
- MTN MoMo details: 0547864825 — Faith Kwasi Nyarko
- WhatsApp order handoff
- PWA manifest/service worker foundation
- Supplied Fresh Chicken logo

## Run
Open `index.html` directly, or serve the folder with any static web server.
